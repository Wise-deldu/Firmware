# Toggle the LED

This project marks the commencement of my first bare metal project.

The purpose of this project is to Toggle the LED.

Before the commencement of the project, three documentations were dowloaded. They are:

* User manual for the STM32F429ZI MCU discovery board.
* Datasheet --- STM32F427xx-STM32F429xx
* Reference manual for STM32F429 and other series

**Note**: Except the User manual for my discovery board, the rest of the documentation are not board specific and all can be downloaded from the [st.com](https://www.st.com/).
